## Дополнение: выравнивание кадров внутри ползунков

Прежние отдельные квадратные обрезки заменены выравниванием по опорным
точкам в `scripts/prepare-comparisons.py`. Используется преобразование подобия:
только сдвиг, одинаковый масштаб по двум осям и поворот всего кадра.
Для губ масштаб и наклон определяются по основанию носа и подбородку,
а положение — по центру линии смыкания губ, без подгонки их ширины и объёма.
Для Full Face используется приближение по переносью, основанию носа и подбородку;
для платизмы — по мочке уха и основанию шеи.

Квадратная область автоматически ограничивается общей областью реальных кадров.
Пустые края не дорисовываются, деформация отдельных черт не применяется.
Обработка выполняется за одно преобразование с бикубической интерполяцией,
затем с прежней умеренной резкостью. Оригинальные коллажи не изменены.
Различия мимики и перспективы сохраняются и не позволяют совместить все контуры
одновременно без деформации фотографии.

Проверка координат подтвердила уменьшение ошибки совмещения выбранных
ориентиров относительно предыдущей версии, равномерность масштаба,
отсутствие выхода за границы исходных кадров и размер всех шести файлов 768 × 768.

Фактическая среднеквадратичная ошибка выбранных ориентиров на полотне 768 px:
губы (центр линии смыкания) 44,0 → 0,0 px; Full Face (три ориентира)
53,0 → 16,5 px; шея (два ориентира) 80,2 → 0,0 px.
Это ошибка выбранных точек, а не всех контуров лица и шеи.
Браузерная проверка всех трёх ползунков, пяти ширин, лайтбоксов,

## Подробности процедур и мобильная запись

Все четыре карточки открывают нативный модальный dialog с описанием и ценой
из существующего сайта; обучение — с условиями по запросу. Новые медицинские
обещания, сроки и состав процедур не добавлялись. Цены обозначены для Элисты;
московская стоимость уточняется отдельно. Из подробностей процедур можно
перейти к выбору города или полному прайсу. Без JS прежние ссылки карточек
остаются рабочими. Нативный dialog блокирует взаимодействие с фоном, закрывается
по Escape, кнопке и клику вне панели; после закрытия фокус возвращается к карточке.

На ширинах до 768 px после первого экрана появляется фиксированная кнопка
выбора города и записи. Она скрывается у раздела записи и ниже, при открытии
меню, просмотра работ и подробностей. Учтён safe-area-inset-bottom; подвал
получает запас места. При изменении высоты контента видимость пересчитывается.
