# Цагана Боваева — сайт косметолога

Адаптивный лендинг для косметолога Цаганы Боваевой: Москва и Элиста,
коррекция губ, ботулинотерапия, увеличение ягодиц и обучение.
Статический сайт без сборки: HTML, CSS и небольшой JavaScript.

## Что важно знать

В исходных данных **нет** телефона, московского адреса, образования, лицензии
и стажа — поэтому на сайте они не выдуманы. Для запуска их нужно уточнить
у специалиста.

Описания процедур, тексты о подходе и часть редакционных формулировок
подготовлены для макета и требуют согласования с Цаганой. Цены и стоимость
обучения нужно сверить перед публикацией.

Сравнения «до / после» взяты из опубликованных «Кейсы» в Instagram. На сайте
есть примечание: результаты индивидуальны, а сроки съёмки и подробности
процедуры уточняются у специалиста.

## Структура

1. Первый экран: оффер, портрет, рейтинг, запись.
2. Обо мне: знакомство, города, направления.
3. Процедуры: четыре направления с ориентиром по цене.
4. Подход: три шага — знакомство, выбор, сопровождение.
5. Цены: основные позиции + полный прайс на 99 услуг.
6. До и после: один фронтальный Full Face с ползунком перед галереей трёх работ.
   Галерея открывается в лайтбоксе, ссылки на Instagram сохранены.
7. Отзывы: 5,0, 36 оценок, три отзыва из DIKIDI.
8. FAQ: как выбрать процедуру, подготовиться и записаться.
9. Запись: выбор города; Элиста — адрес с картой и DIKIDI, Москва — уточнение приёма через VK/Instagram.

### Интерактив

- Мобильное меню и фиксированная шапка.
- Полный прайс в виде 17 раскрывающихся категорий.
- Поиск по названиям услуг и категорий, выбор категории, счётчик результатов
  и сброс фильтров. Поддерживаются несколько слов, разный регистр, ё/е
  и варианты «губы», «ботулинотерапия», «Full Face».
- Подходящие категории раскрываются при фильтрации; сброс возвращает
  состояние раскрытия до поиска. Без JavaScript весь прайс доступен.
- Один ползунок Full Face перед галереей: мышь, касание, стрелки и Home/End.
  Без JavaScript оба кадра видны рядом.
- Лайтбокс для сравнений «до / после»: закрытие по Escape/фону, возврат фокуса.
- FAQ-аккордеон.
- Запись в Элисте через DIKIDI без сбора контактов на сайте; по Москве — связь со специалистом.
- Удержание фокуса в меню и лайтбоксе; закрытые ответы FAQ исключены из навигации.
- Содержимое и навигация доступны при отключённом JavaScript.
- Появление блоков при скролле, поддержка `prefers-reduced-motion`.
- Общие кнопки записи ведут к выбору города на сайте. Элиста — в DIKIDI;
  Москва — в профиль VK для уточнения приёма, также есть ссылка на Instagram.

## Что проверить перед запуском

- Согласовать тексты и описания процедур.
- Сверить 99 цен и стоимость обучения; при изменении прайса обновить блок.
- Добавить телефон, московский адрес и график приёма.
- Уточнить юридические данные и лицензии, добавить политику конфиденциальности.
- Если нужна собственная форма: определить получателя, подключить обработчик
  и проверить фактическое получение заявки.
- Заменить демонстрационную формулировку о правах на фото, если появятся
  новые изображения клиентов. Для фото клиентов нужно отдельное согласие.
- При необходимости заменить домен в Open Graph и favicon.

### Фронтальный Full Face

Новый ползунок использует отдельный фронтальный кейс из актуального «Кейсы».
Исходник — кадр на отметке 1 с из доступного видео 1080 × 1920, самой высокой
наблюдаемой дорожки этой истории. Сохранён без уменьшения:
`assets/source/fullface-front-story-frame.png`.

Пара WebP без потерь размером 468 × 624 px подготовлена без увеличения
разрешения, ретуши и дорисовки. Лица выровнены одновременно по центрам глаз, основанию носа и подбородку:
взвешенное совмещение со сдвигом, равномерным масштабом и поворотом всего кадра. Вёрстка ограничивает
ширину изображения 468 px. Мимика и различия перспективы сохранены.

Подготовка повторяется командой `python3 scripts/prepare-fullface-comparison.py`
(нужен Pillow). Источник и характеристики: `data/fullface-front-source.json`.

### Фото «Обо мне»

Повторный портрет заменён кадром реальной аппаратной процедуры из
[ролика Цаганы](https://www.instagram.com/cosm.cagana/reel/DeHJxA2MM75/).
Маленькая вставка с губами удалена; фото занимает всю ширину своего блока.
Круг рейтинга и пять звёзд сохранены.

Встроенный imagegen использован для очистки наложенного текста. В итоговом
фото применён только небольшой фрагмент восстановления надписи;
лица, руки и кожа клиента взяты из исходного видеокадра с коррекцией экспозиции.
Область аппарата исключена из маски. Фото не используется как доказательство
результата процедуры. Источник, полный запрос и параметры:
`data/cagana-working-source.json`. Повторная подготовка:
`python3 scripts/prepare-work-photo.py` (Pillow).
